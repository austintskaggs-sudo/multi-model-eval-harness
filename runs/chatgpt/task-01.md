**## Summary**

Write a rubric before reviewing outputs, then use it to score the same tasks consistently. Repeat runs to assess stability, and record the model label, date, and time for each run. Check for missed steps, wrong calculations, hallucinated details, and ignored formats.

**## Key points**

- Score the same tasks the same way.
- Write the rubric before looking at outputs.
- Treat one run as a starting point and repeat runs to assess stability.
- Record the model label, date, and time for every run.
- Check for missed steps, wrong calculations, hallucinated details, and ignored formats.

**## Risks**

- Inconsistent scoring can make results difficult to compare.
- A single run can give a misleading impression of stability.
